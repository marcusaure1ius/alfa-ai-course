# Сценарии n8n без кода: маршрут участника

Проверено: 2026-07-23. Это стартовый маршрут для предпринимателя без опыта в n8n.

## Как читать любой сценарий

Во всех десяти уроках одна и та же логика:

1. слева приходит событие;
2. в блоке `1` вы меняете пример;
3. в блоке `2` ИИ выполняет понятную задачу;
4. справа вы проверяете результат.

Код писать, копировать или изучать не нужно. Поля со значком `fx` уже настроены и на первом занятии не меняются. Каждый урок самостоятельный: скрытых Core, Adapter или Helper workflow нет.

## Что подготовлено заранее

- Telegram Trigger для сообщений;
- IMAP Trigger, совместимый с Gmail и Яндекс Почтой;
- Webhook для заявки с сайта;
- Schedule Trigger для ежедневной сводки;
- YandexGPT как основной LLM-путь, доступный аудитории в РФ без обязательного VPN;
- Polza.ai для текста, изображений и мультимодальных запросов с пополнением в рублях;
- безопасный Telegram preview внутри самого урока.

Credential — это сохранённый в n8n доступ к вашему сервису. Секрет вводится один раз в разделе **Credentials** и не вставляется в схему.

## Рекомендуемый порядок

Начните с Telegram и почты: там легче увидеть связь «сообщение → запрос к ИИ → черновик». Затем перейдите к заявке, цифрам руководителя и фильтрации важных писем. Уроки 6–10 — практический блок для малого бизнеса: контент, лиды, личный помощник и документы.

| Урок | Меняет участник | Не меняет участник |
|---:|---|---|
| 1 | вопрос клиента | готовый блок запроса к YandexGPT |
| 2 | тему и текст письма | IMAP-настройки до урока подключения почты |
| 3 | данные учебной заявки | webhook-защиту до урока про сайт |
| 4 | четыре цифры бизнеса | готовый Telegram preview |
| 5 | тему и текст важного письма | обработку вложений и Telegram preview |
| 6 | описание будущей картинки | endpoint и API credential |
| 7 | ссылку на образец и описание изменения | готовый Media API request |
| 8 | текст сообщения лида | Telegram allowlist и отсутствие автозаписи в CRM |
| 9 | контекст бизнеса и вопрос | ограничения помощника и отсутствие автоответа |
| 10 | ссылку на учебное JPG/PNG | формат запроса и запрет автозаписи в учётную систему |

## Когда подключать реальные аккаунты

Сначала добейтесь понятного результата на ручном примере. Затем выберите credential в реальном trigger и проведите один контролируемый тест:

- Telegram — отдельный учебный бот и разрешённый chat ID;
- Gmail — отдельный учебный ящик и IMAP app password/OAuth по политике аккаунта;
- Яндекс Почта — отдельный ящик и пароль приложения для IMAP;
- Yandex AI Studio — отдельный API key в credential n8n.
- Polza.ai — аккаунт, положительный рублёвый баланс и HTTP Header Auth credential с `Authorization: Bearer …`.

Не включайте workflow, пока ручной тест не прошёл и результат не проверен человеком.

## Что считается успехом первого урока

Участник сам меняет пример, запускает workflow и объясняет каждый блок одним предложением. Подключение production-аккаунтов и автоматическая отправка не входят в первый успех.
