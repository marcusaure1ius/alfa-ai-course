# Telegram-поддержка через закрытую группу

Проверено: 2026-07-29. Workflow: `Advanced · Telegram: поддержка через группу`.

Это безопасная адаптация схемы из видео [«Учим телеграмм бота отвечать на сообщения»](https://www.youtube.com/watch?v=XsUb2KOHYWE&t=1028s), а не авторский экспорт JSON.

## Что получится

Пользователь пишет боту в личном чате. Бот пересылает текст в закрытую группу операторов и сохраняет связь между сообщением пользователя и сообщением группы. Оператор нажимает **Ответить** у нужного сообщения, пишет ответ, а бот доставляет этот текст исходному пользователю.

Workflow повторяет показанные в видео блоки:

- `Приём сообщений от бота`;
- разделение личного сообщения и сообщения группы;
- `Новый/старый пользователь`;
- `Новое сообщение` в Google Sheets;
- `Поиск chat_id отправителя`;
- `Отправка ответного сообщения`.

В отличие от ролика, экспорт безопасно выключен: `sendEnabled=false`, разрешённые chat ID заданы placeholders, workflow неактивен, execution payloads не сохраняются.

## 1. Подготовьте Telegram

1. Создайте бота через BotFather.
2. Создайте закрытую группу операторов и добавьте туда бота.
3. Разрешите боту читать сообщения группы.
4. Узнайте отрицательный chat ID группы вида `-100...`.
5. Выпишите только личные chat ID пользователей, которым бот вправе отвечать.
6. В n8n создайте один Telegram credential с token бота.

Token не вставляйте в workflow JSON, Sticky Note, таблицу или Git.

## 2. Подготовьте Google Sheets

Создайте одну таблицу с двумя листами. Первая строка каждого листа — точные имена колонок.

Лист `messages`:

| user_chat_id | user_message_id | group_message_id | text | received_at | route |
|---|---|---|---|---|---|

Лист `users`:

| chat_id | status | last_seen_at |
|---|---|---|

`messages` хранит соответствие, необходимое для обратного ответа. `users` обновляется по `chat_id`; `/start` получает статус `new_or_restart`, остальные сообщения — `known`.

Текст ограничен 2 000 символами, вложения не скачиваются. Если текст обращений хранить нельзя, удалите колонку `text` и её mapping до включения workflow.

## 3. Импортируйте и настройте

1. Импортируйте `workflows/advanced/telegram-support-relay.json`.
2. В `Приём сообщений от бота`, `Отправить в группу` и `Отправка ответного сообщения` выберите Telegram credential.
3. В трёх Google Sheets блоках выберите Google credential и созданную таблицу.
4. Откройте `1. Настройки и безопасный пример`.
5. Вместо `REPLACE_WITH_ALLOWED_PRIVATE_CHAT_IDS` введите разрешённые личные chat ID через запятую.
6. Вместо `REPLACE_WITH_OPERATOR_GROUP_CHAT_ID` введите chat ID закрытой группы.
7. Оставьте `sendEnabled=false`.

## 4. Проверьте без внешних действий

1. Нажмите **Выполнить workflow**.
2. Откройте `1. Настройки и безопасный пример`.
3. Проверьте `manualExpectedRoute`, `forwardText` и `previewOperatorReply`.
4. Откройте выход `0` блока `Новый / известный / ответ?`.

Ожидаемый результат: выполнение заканчивается на ручном preview. Telegram и Google Sheets не вызываются.

## 5. Контролируемый реальный smoke-test

1. Убедитесь, что allowlist содержит только ваш тестовый личный chat ID.
2. Установите `sendEnabled=true`.
3. Активируйте workflow.
4. Напишите боту `/start`, затем одно вымышленное сообщение.
5. В закрытой группе нажмите **Ответить** именно у пересланного сообщения.
6. Отправьте короткий тестовый ответ.
7. Убедитесь, что ответ получил только тестовый пользователь.
8. Снова выключите workflow, пока не проверены правила хранения и список получателей.

Ожидаемый результат:

- в `messages` появилась строка с `group_message_id`;
- в `users` появилась или обновилась строка тестового chat ID;
- Reply из закрытой группы нашёл ровно одну строку;
- Telegram отправил текст исходному разрешённому пользователю.

## Ограничения

- Реальный Telegram/Google smoke не выполнен без user-owned credentials.
- Один операторский Reply должен ссылаться на сообщение, созданное блоком `Отправить в группу`.
- Если строка `group_message_id` удалена или дублируется, ответ не следует отправлять до исправления таблицы.
- Workflow не обрабатывает фото, документы, голосовые сообщения и альбомы.
- Google Sheets подходит для учебного сценария, но не заменяет help desk с ролями, аудитом и политикой удаления данных.
