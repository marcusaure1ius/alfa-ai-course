# Урок 4. Сводка руководителю

Проверено: 2026-07-23. Workflow: `Business · Урок 4 — Сводка руководителю`.

## Что получится

ИИ напишет короткую управленческую сводку по четырём цифрам: заявки, продажи, письма без ответа и просроченные задачи.

## Первый запуск за 10 минут

1. Откройте `1. Введите цифры дня`.
2. Замените четыре числа на вымышленный пример.
3. Нажмите **Выполнить workflow**.
4. Откройте `4. Посмотрите preview`.
5. Проверьте сводку и предложенное действие.

## Как работает расписание

Зелёный блок `Каждый день в 09:00` уже добавлен. До реального включения подключите источник показателей и проверьте часовой пояс n8n.

Telegram работает в безопасном preview: `testMode=true`, `draftOnly=true`. Реальное сообщение не отправляется. Для production нужно отдельное осознанное подключение источника и отключение safe mode после теста.
