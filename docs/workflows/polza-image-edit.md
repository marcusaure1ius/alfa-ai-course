# Урок 7. Новая картинка по образцу

Проверено: 2026-07-23. Workflow: `Business · Урок 7 — Контент: новая картинка по образцу`.

## Что получится

Polza.ai передаст прямую ссылку на исходное изображение модели Qwen Image и попросит изменить фон, свет или стиль. Исходная картинка не редактируется: создаётся новый результат.

## Первый запуск

1. Подключите credential `Polza.ai API` по инструкции урока 6.
2. В `1. Добавьте образец` вставьте публичную прямую ссылку на JPG или PNG.
3. В поле `prompt` простыми словами напишите, что сохранить и что изменить.
4. Нажмите **Выполнить workflow**.
5. Откройте `3. Проверьте результат`.

Учебная ссылка должна открываться без пароля. Не используйте личные фото клиентов, закрытые документы и изображения, на которые у вас нет прав.

## Ограничение

Media API допускает URL и base64. В beginner-уроке оставлена только ссылка: она проще для первого занятия и не требует работы с файлами. Результат не публикуется автоматически.
