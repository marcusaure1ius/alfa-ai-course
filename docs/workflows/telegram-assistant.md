# Урок 1. Telegram: черновик ответа

Проверено: 2026-07-23. Workflow: `Business · Урок 1 — Telegram: черновик ответа`.

## Что получится

ИИ подготовит короткий ответ на вопрос клиента. В Telegram ничего не отправится: результат останется в n8n для проверки человеком.

## Первый запуск за 10 минут

1. Откройте workflow.
2. Прочитайте жёлтую заметку **Начните здесь**.
3. Откройте блок `1. Настройте пример`.
4. В поле `text` напишите вымышленный вопрос клиента.
5. Нажмите **Выполнить workflow**.
6. Откройте последний блок `3. Проверьте черновик`.
7. Прочитайте поле `Черновик ответа`.

Если ИИ не ответил, преподавателю нужно проверить credential Yandex AI Studio в служебном adapter.

## Подключение своего Telegram

1. Создайте учебного бота через BotFather.
2. Сохраните token как Telegram credential в n8n.
3. Выберите его в зелёном блоке `Получить сообщение из Telegram`.
4. Проведите один тест со своего разрешённого chat ID.

Workflow всё равно только готовит черновик. Автоответ клиенту намеренно не входит в первый урок.
