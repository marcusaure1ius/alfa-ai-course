# Урок 6. Картинка по тексту

Проверено: 2026-07-23. Workflow: `Business · Урок 6 — Контент: картинка по тексту`.

## Что получится

Polza.ai создаст одну картинку по обычному русскому описанию. Workflow покажет ссылку и стоимость запроса в рублях, если она есть в ответе API. Ничего автоматически не публикуется.

## Первый запуск

1. Зарегистрируйтесь в [консоли Polza.ai](https://polza.ai/dashboard), пополните баланс и создайте API-ключ.
2. В n8n создайте **HTTP Header Auth** credential: Name — `Authorization`, Value — `Bearer ВАШ_API_КЛЮЧ`.
3. Назовите credential `Polza.ai API` и выберите его в блоке `2. Polza создаёт картинку`.
4. В `1. Опишите картинку` замените поле `prompt`. Не добавляйте персональные данные и чужие бренды.
5. Нажмите **Выполнить workflow** и откройте `3. Проверьте картинку`.

Секрет вводится только в Credentials n8n. Не вставляйте его в поле схемы, документ или чат.

## Проверка результата

Откройте ссылку и проверьте надписи, детали товара, фирменный стиль и права на использование. Модель может ошибаться. Реальную форму через webhook подключайте только с Header Auth и после ручного теста.
