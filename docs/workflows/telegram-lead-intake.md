# Урок 8. Разбор лида из Telegram

Проверено: 2026-07-23. Workflow: `Business · Урок 8 — Telegram: разбор нового лида`.

## Что получится

ИИ выделит из входящего сообщения имя, контакт, потребность, срочность, недостающие данные и следующий вопрос менеджера. Карточка останется в n8n для проверки.

## Первый запуск

1. Выберите `Polza.ai API` в блоке `2. Polza собирает карточку`.
2. Измените вымышленное сообщение в `1. Настройте обращение`.
3. Нажмите **Выполнить workflow**.
4. Сверьте карточку с исходным сообщением.

## Подключение Telegram

1. Создайте отдельного учебного бота через BotFather.
2. Сохраните token как Telegram credential в n8n.
3. Выберите credential в `Получить лид из Telegram`.
4. Замените `REPLACE_WITH_ALLOWED_CHAT_IDS` на разрешённый chat ID.
5. Отправьте боту одно тестовое сообщение без реальных персональных данных.

Workflow не отвечает клиенту и не меняет CRM. Менеджер переносит проверенную карточку вручную.
