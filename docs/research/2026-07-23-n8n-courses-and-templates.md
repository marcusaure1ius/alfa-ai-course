# Курсы n8n и библиотеки готовых сценариев для аудитории РФ

Проверено: 2026-07-23. Цены и программы меняются; перед покупкой их нужно проверить повторно.

## Короткий вывод

Для аудитории курса, которая раньше пользовалась только ChatGPT, лучший путь — сначала пройти наши пять коротких уроков, затем дать один бесплатный русскоязычный курс как повторение и только потом показывать библиотеки шаблонов.

Не стоит массово импортировать чужие JSON. Внешний шаблон может содержать Code nodes, недоступные из РФ модели, автоматическую отправку писем, платные API и небезопасную обработку данных.

## Что можно заимствовать в наш курс

1. Из бесплатного курса Карташова — порядок «интерфейс → первый workflow → Telegram → Google», но заменить OpenRouter на YandexGPT.
2. Из Stepik — короткие контрольные вопросы после каждого урока.
3. Из `n8n-courses.ru` — показ результата в начале урока и Telegram как основной интерфейс.
4. Из «Точки сборки» — формат постоянно растущей библиотеки, но каждый сценарий пропускать через наш no-code и safety gate.
5. Из курса для маркетологов — будущие уроки по Яндекс Метрике, Яндекс Директ, VK и Битрикс24.
6. Из Cloud.ru — простой дополнительный сценарий с курсом ЦБ РФ, но запускать его на нашей защищённой архитектуре.

## Готовые community templates, которые близки к нашим урокам

- [Telegram AI assistant с текстом и голосом](https://n8n.io/workflows/2534-telegram-ai-bot-assistant-ready-made-template-for-voice-and-text-messages/) — готовый JSON, но требует OpenAI/Whisper; использовать только как идею для будущего YandexGPT-варианта.
- [Gmail triage → Gemini → Telegram](https://n8n.io/workflows/16032-triage-gmail-and-send-high-priority-alerts-with-gemini-and-telegram/) — почти совпадает с уроком 5, но использует Gmail OAuth, Gemini, Data Table и реальную отправку.
- [Gmail newsletters → Telegram digest](https://n8n.io/workflows/7254-on-demand-email-newsletter-summaries-from-gmail-to-telegram-with-gpt-41-mini/) — содержит несколько Code nodes и OpenAI, поэтому для нашей аудитории не подходит без полной пересборки.
- [Telegram + локальные Ollama и Whisper](https://n8n.io/workflows/6012-create-a-privacy-focused-ai-assistant-with-telegram-ollama-and-whisper/) — не требует зарубежного LLM API, но требует отдельного сервера моделей и слишком сложен для первого модуля.

## Рекомендация

Не покупать курс только ради «тысяч готовых JSON». Для нашей программы полезнее:

1. сохранить пять тщательно проверенных beginner-уроков;
2. добавить ещё 5–7 уроков под РФ-сервисы: ЦБ РФ, VK, Яндекс Метрика, Битрикс24, Google/Яндекс Почта;
3. брать внешние шаблоны только как описание бизнес-идеи;
4. каждый выбранный сценарий пересобирать в формате 5–8 визуальных блоков без Code nodes и автоматических опасных действий.
