# Десять готовых уроков в n8n

Проверено: 2026-07-23. Шаблоны рассчитаны на человека, который раньше видел только чат с ИИ. В учебном n8n находятся только десять уроков. В них нет Code, Function, JavaScript nodes и служебных sub-workflows.

## Что открыть

В поиске n8n введите `Урок`. Появятся десять сценариев:

| Урок | Название в n8n | Результат |
|---:|---|---|
| 1 | `Business · Урок 1 — Telegram: черновик ответа` | ИИ готовит ответ клиенту, но ничего не отправляет |
| 2 | `Business · Урок 2 — Почта: черновик ответа` | ИИ пишет черновик ответа на письмо |
| 3 | `Business · Урок 3 — Заявка: карточка лида` | ИИ превращает текст заявки в понятную карточку |
| 4 | `Business · Урок 4 — Сводка руководителю` | ИИ пишет короткую сводку по четырём цифрам |
| 5 | `Business · Урок 5 — Важное письмо → Telegram` | ИИ оценивает письмо и показывает Telegram preview |
| 6 | `Business · Урок 6 — Контент: картинка по тексту` | ИИ создаёт изображение по описанию |
| 7 | `Business · Урок 7 — Контент: новая картинка по образцу` | ИИ меняет фон или стиль исходного изображения |
| 8 | `Business · Урок 8 — Telegram: разбор нового лида` | ИИ превращает сообщение в карточку лида |
| 9 | `Business · Урок 9 — Telegram: персональный ИИ-помощник` | ИИ готовит совет или рабочий черновик |
| 10 | `Business · Урок 10 — Бухгалтерия: разбор первичного документа` | ИИ извлекает реквизиты из фото для ручной сверки |

У каждого урока всего 5–6 рабочих блоков. Схема читается слева направо. Жёлтая заметка внутри объясняет первое действие.

## Подготовка преподавателя

Один раз до занятия:

1. Создайте credential `Yandex AI Studio Api-Key` для уроков 1–5.
2. Создайте HTTP Header Auth credential `Polza.ai API` для уроков 6–10. Поле Name: `Authorization`, Value: `Bearer ВАШ_API_КЛЮЧ`.
3. В каждом уроке откройте блок `2. …` и выберите нужный credential.
4. В уроках 1–5 замените `REPLACE_WITH_FOLDER_ID` в полях `folderId` и `model`.
5. Запустите по одному уроку каждого провайдера вручную на вымышленном примере.

Для Polza.ai сначала нужна [регистрация в консоли](https://polza.ai/dashboard), рублёвое пополнение и API-ключ. Ключ вводится только в Credentials n8n, не в workflow и не в чат.

Других workflow для работы уроков не требуется.

## Шаблон занятия на 10–15 минут

1. Покажите результат, который получит предприниматель.
2. Нажмите **Выполнить workflow**.
3. Откройте блок `1. Настройте…` и замените только текст примера.
4. Запустите ещё раз и сравните ответ ИИ.
5. Покажите реальный зелёный trigger слева: Telegram, почта, webhook или расписание.
6. Объясните, что реальный аккаунт подключается выбором credential, а не программированием.
7. Оставьте workflow выключенным до отдельной проверки реального аккаунта.

## Безопасность первого занятия

- все workflow импортируются выключенными;
- Telegram и email не отправляются автоматически;
- почтовые вложения не скачиваются;
- сводка и важное письмо заканчиваются локальным Telegram preview без блока отправки;
- новые Telegram-уроки требуют разрешённый chat ID и не отвечают автоматически;
- уроки с изображениями не публикуют результат;
- бухгалтерский урок ничего не записывает в 1С, таблицу или банк и требует сверки с оригиналом;
- API keys, пароли почты и Telegram token хранятся только в Credentials n8n;
- для первого запуска используются вымышленные данные.
