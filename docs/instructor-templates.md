# Пять готовых уроков в n8n

Проверено: 2026-07-23. Шаблоны рассчитаны на человека, который раньше видел только чат с ИИ. В учебном n8n находятся только пять уроков. В них нет Code, Function, JavaScript nodes и служебных sub-workflows.

## Что открыть

В поиске n8n введите `Урок`. Появятся пять сценариев:

| Урок | Название в n8n | Результат |
|---:|---|---|
| 1 | `Business · Урок 1 — Telegram: черновик ответа` | ИИ готовит ответ клиенту, но ничего не отправляет |
| 2 | `Business · Урок 2 — Почта: черновик ответа` | ИИ пишет черновик ответа на письмо |
| 3 | `Business · Урок 3 — Заявка: карточка лида` | ИИ превращает текст заявки в понятную карточку |
| 4 | `Business · Урок 4 — Сводка руководителю` | ИИ пишет короткую сводку по четырём цифрам |
| 5 | `Business · Урок 5 — Важное письмо → Telegram` | ИИ оценивает письмо и показывает Telegram preview |

У каждого урока всего 5–6 рабочих блоков. Схема читается слева направо. Жёлтая заметка внутри объясняет первое действие.

## Подготовка преподавателя

Один раз до занятия:

1. Создайте один credential `Yandex AI Studio Api-Key` в n8n.
2. В каждом уроке откройте блок `2. ИИ…` и выберите этот credential.
3. В блоке `1. Настройте…` замените `REPLACE_WITH_FOLDER_ID` в полях `folderId` и `model`.
4. Запустите любой урок вручную на вымышленном примере.

Других workflow для работы уроков не требуется.

## Шаблон занятия на 10–15 минут

1. Покажите результат, который получит предприниматель.
2. Нажмите **Выполнить workflow**.
3. Откройте блок `1. Настройте…` и замените только текст примера.
4. Запустите ещё раз и сравните ответ ИИ.
5. Покажите реальный зелёный trigger слева: Telegram, почта, webhook или расписание.
6. Объясните, что реальный аккаунт подключается выбором credential, а не программированием.
7. Оставьте workflow выключенным до отдельной проверки реального аккаунта.

## Безопасность первого занятия

- все workflow импортируются выключенными;
- Telegram и email не отправляются автоматически;
- почтовые вложения не скачиваются;
- сводка и важное письмо заканчиваются локальным Telegram preview без блока отправки;
- API keys, пароли почты и Telegram token хранятся только в Credentials n8n;
- для первого запуска используются вымышленные данные.
