# License notes

Проверено: 2026-07-14 по официальному тексту лицензии и FAQ n8n. Этот документ фиксирует продуктовую интерпретацию для текущей модели starter kit, не заменяет условия правообладателя и не является юридической консультацией.

## n8n

Основная codebase n8n распространяется по [Sustainable Use License 1.0](https://github.com/n8n-io/n8n/blob/master/LICENSE.md). Исключения, включая enterprise-файлы и third-party components, сохраняют собственные условия. Официальный [n8n license FAQ](https://docs.n8n.io/sustainable-use-license/) описывает модель как fair-code и приводит consulting, создание workflow и поддержку внутреннего n8n server как разрешённые примеры.

Текст лицензии ограничивает использование и модификацию собственными внутренними бизнес-задачами либо некоммерческим/личным использованием; бесплатная передача другим лицам разрешена только для некоммерческих целей и с сохранением notices. FAQ помогает применить эти условия к продуктовым примерам, но не заменяет сам текст лицензии.

Для этого проекта допустимый сценарий означает:

- участник разворачивает и контролирует собственный n8n для внутренних процессов;
- starter kit предоставляет инструкции, конфигурацию, workflow и поддержку;
- доступ к hosted n8n не продаётся;
- n8n не переименовывается и не предлагается как white-label продукт;
- исходные license, copyright и trademark notices не удаляются.

Starter kit не копирует source code или image n8n: deployment загружает официальный container image по закреплённому tag. Передача оригинальных документов, Compose configuration и workflow этого репозитория не меняет лицензию n8n и не даёт получателю дополнительных прав на n8n.

Без отдельной проверки и соглашения нельзя использовать этот комплект как основание для:

- платного multi-tenant или managed n8n access;
- white-label n8n offering;
- сервиса, ценность которого полностью или существенно состоит в предоставлении функциональности n8n клиентам;
- backend, который собирает credentials конечных пользователей способом, не покрытым разрешёнными примерами n8n.

Официальное FAQ отдельно указывает, что white-label n8n и платный hosting/access не разрешены этой лицензией, а сценарии вне разрешённых границ требуют отдельного коммерческого соглашения. При сомнениях нужно обратиться к `license@n8n.io` до запуска или продажи соответствующего сценария.

## Starter kit и зависимости

Лицензия самого starter kit будет зафиксирована отдельным release-решением до публичного распространения. Каждый included dependency и container image сохраняет собственную лицензию; наличие файла этого проекта не заменяет их условия.

`LICENSE-NOTES.md` сам по себе не выдаёт лицензию на оригинальные файлы starter kit. До выбора отдельного `LICENSE` публичный release или передача прав на повторное распространение остаются заблокированы; участник получает только те материалы и права использования, которые явно определены организатором курса.

До release review необходимо:

1. выбрать и добавить лицензию для оригинальных файлов starter kit;
2. собрать notices и attribution для распространяемых файлов и assets;
3. повторно проверить n8n license и business model;
4. не включать vendor binaries или чужие assets без понятного права на распространение.
5. добавить release notes или `CHANGELOG.md` с exact pins, migration/recovery notes, фактически выполненными проверками и известными внешними gaps.

Фактическая основа решения и полный список источников находятся в [dated research note](docs/research/2026-07-13-platform-versions-and-license.md).
